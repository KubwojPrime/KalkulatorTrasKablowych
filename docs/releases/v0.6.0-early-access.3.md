# Kalkulator Tras Kablowych 0.6.0 — Early Access 3

Wydanie naprawcze instalatora Windows.

## Poprawka

W Early Access 2 walidacja katalogu była wykonywana przez zdarzenie NSIS
uruchamiane przy każdej zmianie pola ścieżki. Powodowało to wielokrotne
wyświetlanie ostrzeżenia „Wybierz pusty folder” i mogło uniemożliwić wpisanie
poprawnej lokalizacji.

W EA3 katalog można swobodnie wpisać lub wybrać. Walidacja jest wykonywana
dopiero po kliknięciu „Dalej”. Ostrzeżenie pojawia się tylko wtedy, gdy końcowy
katalog jest niepusty i nie zawiera znacznika wcześniejszej instalacji.

Pozostałe funkcje instalatora nie zmieniły się:

- obowiązkowa akceptacja EULA;
- wybór katalogu instalacji;
- domyślny skrót w menu Start;
- opcjonalny skrót na pulpicie;
- instalacja bez uprawnień administratora;
- ochrona obcych plików podczas deinstalacji.
