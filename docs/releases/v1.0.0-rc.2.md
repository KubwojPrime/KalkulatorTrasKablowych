# Kalkulator Tras Kablowych 1.0.0 — Release Candidate 2

Wydanie testowe Windows x64, zastępujące RC1 do dalszego odbioru.

## Zmiany

- Poprawiony DXF 2007: kompletna struktura dokumentu, poprawne tabele i właściciele obiektów. Dodano kontrolę surowych rekordów i niezależny audyt bez napraw. Użytkownik potwierdził poprawny odczyt po poprawce.
- Wyszukiwanie tras BAKS po symbolu, nazwie, numerze katalogowym i aliasach, np. KCJ200H60 / KCJ300H60 dla rodziny KCJ/KCOJ. Filtrowanie zachowuje dobrany zestaw.
- Robocze logo w programie, ikonie EXE i instalatorze.
- Uzupełnione README, instrukcje pobierania i zgłaszania problemów oraz zrzuty interfejsu.

## Instalacja i aktualizacja

Pobierz `KalkulatorTrasKablowych-1.0.0-win64-setup.exe` albo cały ZIP z załączników.
Zamknij poprzednią wersję, zabezpiecz projekty XLSX i instaluj do dotychczasowego folderu.
Ponownie wyeksportuj DXF utworzone w RC1 lub wcześniejszych wersjach.
Numer techniczny EXE pozostaje 1.0.0; wydanie identyfikuje tag `v1.0.0-rc.2`.

EXE i setup podpisano SSC ze znacznikiem czasu. Ostrzeżenia Windows o nieznanym
wystawcy są możliwe. Załączono publiczny certyfikat, jego opis oraz SHA256SUMS.
Instrukcja weryfikacji: https://github.com/KubwojPrime/KalkulatorTrasKablowych/blob/v1.0.0-rc.2/docs/early-access-signature.md

## Ograniczenia

To nadal prerelease, nie finalne wydanie 1.0.0. Pozostają pełny odbiór Windows 10/11,
przegląd EULA i obowiązków dystrybucji zależności oraz weryfikacja danych do projektów.
Logo jest robocze; podobieństwo do istniejących marek wymaga dalszej oceny.
Program nie zastępuje projektanta ani rzeczoznawcy ppoż.

Zgłoszenia: https://github.com/KubwojPrime/KalkulatorTrasKablowych/issues
