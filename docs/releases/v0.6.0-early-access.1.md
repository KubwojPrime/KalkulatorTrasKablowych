# Kalkulator Tras Kablowych 0.6.0 — Early Access 1

Pierwsze wydanie testowe przygotowane do instalacji na Windows 10/11. Nie jest
to jeszcze wersja 1.0.0 i nie powinna być używana jako jedyne źródło wyników w
obliczeniach wpływających na bezpieczeństwo pożarowe lub konstrukcyjne.

## Zakres

- kalkulacja wypełnienia trasy, masy i obciążenia ogniowego;
- katalog 25 065 kabli czterech producentów;
- elementy tras BAKS, w tym rodzina KCJ;
- filtry katalogu oraz wyszukiwanie wielowyrazowe;
- import i eksport projektu XLSX;
- wizualizacja przekroju trasy;
- instalator per-user i wersja przenośna ZIP.

## Podpis Early Access

Plik aplikacji i instalator są podpisane samopodpisanym certyfikatem
Authenticode z zewnętrznym znacznikiem czasu DigiCert.

- podmiot: `CN=Kalkulator Tras Kablowych Early Access, O=KubwojPrime`;
- odcisk SHA-1: `C5BE5238453A8A9A93DB9AC6C755560147A00320`;
- odcisk SHA-256 publicznego certyfikatu:
  `1E9F88E07CD9A60BBE69E83E67586A03621198218DC1F0BFD4B11174D5C4764C`;
- ważność certyfikatu: 4.08.2026–4.08.2029.

Certyfikat nie jest wydany przez publiczny urząd certyfikacji. Windows pokaże
niezaufanego wydawcę, dopóki administrator testowego komputera nie zweryfikuje
odcisku i nie doda załączonego pliku `.cer` do zaufanych certyfikatów.

Przed uruchomieniem należy sprawdzić pliki przy użyciu dołączonego
`SHA256SUMS-0.6.0.txt` oraz przeczytać `docs/early-access-signature.md`.

## Zgłaszanie problemów

Zgłoszenie powinno zawierać wersję Windows, opis kroków, oczekiwany i otrzymany
wynik oraz — jeśli problem dotyczy danych — producenta, oznaczenie kabla i nazwę
materiału źródłowego. Nie należy dołączać poufnych projektów ani list kablowych.
