# Kalkulator Tras Kablowych 0.6.0 — Early Access 4

Drugie wydanie naprawcze strony wyboru katalogu instalacji.

## Poprawka

Early Access 3 poprawnie ograniczył wyświetlanie komunikatu do kliknięcia
„Dalej”, ale używany test wildcard NSIS nadal mógł rozpoznać istniejący pusty
folder jako niepusty z powodu technicznych wpisów katalogowych `.` i `..`.

EA4 sprawdza zawartość katalogu przez `FindFirst/FindNext`, jawnie pomija `.` i
`..` oraz akceptuje:

- katalog, który jeszcze nie istnieje;
- istniejący pusty katalog;
- katalog wcześniejszej instalacji z prawidłowym znacznikiem.

Istniejący niepusty obcy katalog pozostaje blokowany, ponieważ jego rekurencyjne
usunięcie podczas deinstalacji mogłoby skasować pliki użytkownika.

Test pakietu tworzy teraz fizycznie istniejący pusty folder przed instalacją,
sprawdza instalację do ścieżki ze spacjami, a następnie osobno potwierdza
odrzucenie folderu zawierającego obcy plik.

## Podpis Early Access

Plik aplikacji i instalator są podpisane samopodpisanym certyfikatem
Authenticode z zewnętrznym znacznikiem czasu DigiCert.

- podmiot: `CN=Kalkulator Tras Kablowych Early Access, O=KubwojPrime`;
- odcisk SHA-1: `C5BE5238453A8A9A93DB9AC6C755560147A00320`;
- odcisk SHA-256 publicznego certyfikatu:
  `1E9F88E07CD9A60BBE69E83E67586A03621198218DC1F0BFD4B11174D5C4764C`.

Przed uruchomieniem należy porównać pliki z `SHA256SUMS-0.6.0.txt`.
