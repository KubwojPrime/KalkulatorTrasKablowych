# Kalkulator Tras Kablowych 0.6.0 — Early Access 5

Wydanie zmienia zakres instalacji z bieżącego użytkownika na instalację
systemową dla wszystkich użytkowników komputera.

## Uprawnienia administratora

Setup i deinstalator mają manifest `requireAdministrator`. Windows wyświetla
okno UAC przed uruchomieniem instalatora. Po zaakceptowaniu można instalować
program w chronionych lokalizacjach, takich jak `C:\Program Files` albo
`E:\Program Files`.

Pozostałe zmiany:

- domyślna lokalizacja: `%ProgramFiles%\Kalkulator Tras Kablowych`;
- rejestracja instalacji i deinstalatora w 64-bitowej gałęzi `HKLM`;
- skróty menu Start tworzone dla wszystkich użytkowników;
- opcjonalny skrót na wspólnym pulpicie;
- deinstalator również wymaga zgody UAC;
- zachowana ochrona pustego i niepustego katalogu z EA4.

Przed instalacją EA5 zalecane jest odinstalowanie wcześniejszej wersji per-user,
aby uniknąć dwóch niezależnych kopii programu.

Plik aplikacji i instalator są podpisane samopodpisanym certyfikatem
Authenticode z zewnętrznym znacznikiem czasu DigiCert.

- podmiot: `CN=Kalkulator Tras Kablowych Early Access, O=KubwojPrime`;
- odcisk SHA-1: `C5BE5238453A8A9A93DB9AC6C755560147A00320`;
- odcisk SHA-256 publicznego certyfikatu:
  `1E9F88E07CD9A60BBE69E83E67586A03621198218DC1F0BFD4B11174D5C4764C`.

Przed uruchomieniem należy porównać pliki z `SHA256SUMS-0.6.0.txt`.
