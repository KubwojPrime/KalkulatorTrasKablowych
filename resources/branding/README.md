# Logo Moduł

Wybrana przez autora propozycja nr 3, bez nazwy i napisów, grafit + niebieski.
`logo-module.png` zachowuje oryginalną zaakceptowaną grafikę z przezroczystością.
`app-icon.png` i `app.ico` są wersjami użytkowymi na jasnym tle dla czytelności
na ciemnym pasku zadań. ICO zawiera rozmiary 16, 20, 24, 32, 40, 48, 64, 128 i 256 px.

Odtwarzanie plików użytkowych w Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-brand-icons.ps1
```

Skrypt tylko przycina przezroczyste marginesy, skaluje zaakceptowany znak
i umieszcza go na neutralnym tle; nie przerysowuje ani nie zmienia symbolu.
